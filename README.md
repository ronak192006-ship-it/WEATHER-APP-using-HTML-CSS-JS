
# 🌤️ Weather App

A responsive weather application built using
1"HTML", 
2"CSS",
3"JavaScript"
that provides real-time weather information for searched cities and the ***user's current location***.

## 🚀 Live Features

- 🔍 Search weather by city name (example :- New Delhi)
- 📍 Get weather using the user's current location
- 🌡️ Display current temperature (in Celsius °C)
- 🌤️ Display weather condition and description
- 💧 Display humidity
- 💨 Display wind speed
- 🖼️ Weather background based on weather conditions
- ⚠️ Error handling for invalid or unavailable cities
- 📱 Responsive user interface

## 🛠️ Technologies Used

- **HTML** — Structure of the application
- **CSS** — Styling, layout, responsiveness, and UI
- **JavaScript (ES6+)** — Application logic and API handling
- **OpenWeatherMap API** — Real-time weather data
- **Font Awesome** — Icons
